# Evidencia 1 - Procesamiento y Búsqueda de Bitácoras (Logs)

## Instrucciones de Compilación y Ejecución
Para compilar este proyecto desde la terminal, asegúrate de tener instalado el compilador GCC (C++). Debes ubicarte en el directorio raíz del proyecto o en la carpeta `src` donde tengas tu código fuente y ejecutar el siguiente comando:

`g++ -o app main.cpp`

Una vez compilado exitosamente, puedes iniciar la aplicación ejecutando el binario generado:

`./app` (en sistemas Unix/Linux/Mac) o `app.exe` (en Windows)

Asegúrate de que los archivos de datos `log607-1.txt` y `log607-2.txt` estén ubicados en la misma ruta desde donde estás ejecutando el binario para que el programa pueda leerlos correctamente.

## Formato de Fechas Esperado para la Búsqueda
Al utilizar la funcionalidad de búsqueda binaria por rango temporal, el sistema te pedirá ingresar la fecha y hora de inicio y de fin. El formato estricto que debes utilizar requiere tres letras para el mes en inglés (con la primera mayúscula), seguido del día, el año y la hora exacta separada por dos puntos[cite: 1]. 

Ejemplo de entrada válida:
`Sep 12 2025 04:33:01`

## Política de Uso de Inteligencia Artificial
Durante el desarrollo de esta evidencia, se aplicó un criterio formativo sobre el uso de herramientas de Inteligencia Artificial. Se permitió el uso de asistentes como apoyo metodológico para resolver dudas puntuales de sintaxis en C++, comprender mensajes de error del compilador y recibir revisiones o críticas sobre fragmentos de código escritos manualmente. 

Quedó estrictamente prohibido pegar el enunciado completo de la actividad para que la IA generara la solución de punta a punta, así como el uso de asistentes agénticos (Copilot en modo agente, Claude Code, Cursor) para resolver el proyecto en un solo paso, ya que esto no genera evidencia de aprendizaje real. Se garantiza la capacidad de explicar y defender cada línea del código fuente entregado. Los prompts específicos y las correcciones de errores detectados en la IA se detallan en el documento de reflexión final.
