# Procesador de Logs de Red - Evidencia 2

Este proyecto implementa estructuras de datos lineales desde cero (Listas doblemente ligadas, Pilas y Filas) para el procesamiento, ordenamiento y análisis de bitácoras de red.

## Instrucciones de Compilación y Ejecución
1. Abre tu terminal en el directorio raíz del proyecto (donde se encuentran las carpetas `src`, `include` y `data`).
2. Compila el código fuente ejecutando:
   `g++ src/main.cpp -o app_logs`
3. Ejecuta el archivo binario:
   En Windows: `.\app_logs.exe`
   En Mac/Linux: `./app_logs`

## Uso del Programa
Al iniciar, el programa te solicitará el nombre del archivo. Asegúrate de ingresar únicamente el nombre (ej. `log607-1.txt` o `log607-2.txt`). El sistema buscará automáticamente en la carpeta `/data/`.

**Formato de Búsqueda de Fecha:**
Para las opciones 2 y 3, debes ingresar la fecha usando el formato de tres letras para el mes (en inglés), día y año.
Ejemplo: `Sep 14 2024`
